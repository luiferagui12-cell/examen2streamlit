# 🏢 Sistema de Gestión de Empleados - TechZone (Examen Tema 2)

Aplicación web modular desarrollada en **Python** con **Streamlit** y manejo de datos integrados, diseñada para la gestión eficiente de inventarios y personal.

---

## 🛠️ Tecnologías Utilizadas
* **Frontend**: Streamlit (`examen2streamlit.py`)
* **Datos**: Excel / SQLite (`InventarioTechZone.xlsx`)
* **Control de Versiones**: Git & GitHub
